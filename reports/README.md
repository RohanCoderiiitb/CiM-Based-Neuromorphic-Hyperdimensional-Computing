# Reports

One report per phase, generated by the phase's own `make_report` script from its measured results (so a report never carries a number its data do not). Figures are linked from [`../figures/`](../figures/).

| phase | report | the answer in one line |
|---|---|---|
| 0 | [phase0_report.md](phase0_report.md) | the integer reference model is bit-exact against the float model; golden vectors exported |
| 1A | [phase1a_report.md](phase1a_report.md) | device values from the Stanford-PKU model (541.8 / 218,586 ohm), PTM 45 nm LP access transistor, a Newton solver validated against ngspice |
| 1B-i | [phase1b_provisional_report.md](phase1b_provisional_report.md) | the margin budget without wire or drift: provisional g |
| 1B | [phase1b_report.md](phase1b_report.md) | wire IR and drift added: g = 8 (marginal), contiguous groups, per-group ladder |
| 1C | [phase1c_report.md](phase1c_report.md) | the full 512 x 160 array: both-end drivers, rails, 160 columns at once, area and energy |
| 1D-i | [phase1d_i_report.md](phase1d_i_report.md) | the write path on the array: 160 devices per pulse; the 1.1 V access transistor caps RESET and needs thick-oxide drivers |
| 1D-ii | [phase1d_ii_report.md](phase1d_ii_report.md) | the compiled compact model: sigma_lnG 0.03-0.08 (model) from program-verify; the 20 F^2 cell cannot write 1A's states; read disturb |
| 1E | [phase1e_report.md](phase1e_report.md) | the SNN RTL, bit-exact against the golden vectors, synthesised |
| 1F | [phase1f_report.md](phase1f_report.md) | the sense front-end: mismatch-dominated, per-column calibration, g = 4 is the honest design point |

`archive/` holds superseded versions (1A v1). Paths quoted inside the 1A-1D and 1F reports (`results/...`, `margin/...`) are relative to [`../studies/crossbar/`](../studies/crossbar/); inside 1E to [`../design/rtl/`](../design/rtl/); inside 0 to [`../design/reference_model/`](../design/reference_model/).

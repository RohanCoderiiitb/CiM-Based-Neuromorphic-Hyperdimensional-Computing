# Design - what is implemented

| folder | contents | entry point |
|---|---|---|
| [`rtl/`](rtl/) | the Phase 1 SNN in SystemVerilog (`rtl/phase1_snn/`, `rtl/pkg/`) and the Phase 2-4 additions (`rtl/phase2_hdc/` HDC query, `rtl/phase4_exit/` margin early exit, `rtl/phase3_top/` the integration), their cocotb / SystemVerilog testbenches, lint / regression / synthesis / power scripts and results | [`rtl/README.md`](rtl/README.md), reports [`phase1e`](../reports/phase1e_report.md), [`phase234`](../reports/phase234_report.md), [`phase5_ppa`](../reports/phase5_ppa.md) |
| [`reference_model/`](reference_model/) | the bit-exact fixed-point reference of NeuroHDC (Phase 0), extended for Phases 2-4 (`hdc_query.py`: both class-HV mappings, top-2, margin, early exit; `r1_model.py`: the R=1 networks): the integer model, the frozen trained weights, and the golden test vectors the RTL is checked against (`tb/vectors/`) | [`reference_model/README.md`](reference_model/README.md), report [`../reports/phase0_report.md`](../reports/phase0_report.md) |
| [`crossbar/`](crossbar/README.md) | the ReRAM crossbar as designed: **the parameterised SPICE netlist generator** (`crossbar_netlist/`: cell, group, macro, array; validated against the mesh solver, report [`crossbar_netlist.md`](../reports/crossbar_netlist.md)), and the design sheet - every decision with the report section behind it. The device model (`rram.va`) and the PTM transistor card live with the simulations in [`../studies/crossbar/`](../studies/crossbar/) | [`crossbar/README.md`](crossbar/README.md) |
